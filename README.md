# Face Recognition

Yüz tanıma ve yüz doğrulama üzerine iki proje.

| Klasör | İçerik |
|---|---|
| [`face_try/`](face_try/) | YOLOv8-face + SFace ile gerçek zamanlı yüz tanıma, FastAPI web arayüzü |
| [`face_verification/`](face_verification/) | SCRFD/MTCNN dedektörleri ile ArcFace/FaceNet embedding'lerinin karşılaştırması (t-SNE, ROC/EER) |

Her klasörün kendi README'si ve `requirements.txt` dosyası var.
